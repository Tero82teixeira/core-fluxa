# Plano: equipe e permissões

1. Consolidar matriz papel × capacidade e aprová-la com produto.
2. Mapear cada ação de UI à função/RLS equivalente; UI nunca será a autorização final.
3. Adicionar testes de convite, aceite, expiração, remoção, rebaixamento e último proprietário.
4. Implantar trilha de auditoria para mudanças de papel e exportar evidências.
5. Liberar por feature flag após testes multitenant em staging.
